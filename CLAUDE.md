# K-VeriAI — working notes for agents

- Next.js 16 App Router: `proxy.ts` (not middleware), async `params`/`searchParams`/`cookies()`, `PageProps<"/route">` typed helpers (run `pnpm next typegen` after adding routes). Read `node_modules/next/dist/docs/` before using unfamiliar APIs.
- Prisma 7 with `@prisma/adapter-pg`; client generated to `src/generated/prisma` (gitignored) — run `pnpm prisma generate` after `pnpm install`. Config in `prisma.config.ts`; seed via `pnpm prisma db seed`.
- Server Actions live in `actions.ts` next to pages and must only export async functions; always call `requireUser()` / `requireRole()` first.
- Evaluation engine (`src/lib/eval`): keep DEMO mode deterministic (seeded PRNG) and keep `DemoJudge` key heuristics in sync with scenario annotation keys in `prisma/seed-data/library.ts`. Imported JSONL scenarios (`src/lib/library/import-jsonl.ts`) use the annotation keys in its `SCHEMAS` map and `demoFailureMode` hints read by `DemoAdapter.setFailureHint`; keep both in sync with `DemoJudge`. Scenario queries must use `scenarioScope(orgId)` (global + own org).
- i18n: UI strings `src/lib/i18n/dict.ts` (en→xx), enum labels `labels.ts`, report strings `src/lib/reports/dict.ts`; per-language files in `src/lib/i18n/locales/`. New UI text must be wrapped in `t("…")` and added to every locale dict. Framework/requirement/control text is translated via `prisma/seed-data/i18n/<lang>.json` + `src/lib/i18n/content.ts` (`localizeFramework/Requirement/Control`); when `frameworks.json` changes, update `_source.json` and every language file, then run `python3 scripts/check-framework-i18n.py`. Test-library metadata (not prompts) is translated via `prisma/seed-data/i18n/library.<lang>.json` + `src/lib/i18n/library.ts`; regenerate with `pnpm tsx scripts/build-library-i18n-source.ts`, validate with `python3 scripts/check-library-i18n.py`.
- Evidence coverage: always use `validEvidenceWhere(orgId, systemId)` / `evidenceCountsFor` from `src/lib/documents.ts` (system + organisation-wide evidence, VALID, not expired). Governance documents live in `Policy` (UI "Policies & documents"); never change document-managed evidence (`policyId`) directly — go through the document actions.
- Framework requirements come from `docs/framework-control-library.md` → `python3 prisma/seed-data/build-frameworks.py` → `prisma/seed-data/frameworks.json`. Edit the markdown, not the JSON.
- Checks before pushing: `pnpm tsc --noEmit && pnpm lint && pnpm build`.
